Biscuit Portal Broadcast Builder

What This Is

The Biscuit Portal Broadcast Builder is a simple HTML tool that lets you type a message and turn it into a single captive portal HTML page.

You type the message into the builder, click Submit, download the generated HTML file, and upload that file to your Biscuit captive portal.

When someone connects to the Biscuit WiFi portal, the message displays directly on the captive portal page.

How To Use It

1. Open the Biscuit Portal Broadcast Builder in your browser.

2. Type your broadcast title.

3. Type the message you want people to see.

4. Click Submit.

5. Click Download HTML Portal.

6. Upload the generated HTML file to your Biscuit captive portal.

7. Connect a phone to the Biscuit WiFi portal.

8. Open the captive portal.

9. The broadcast message should appear on the page.

What It Does

The builder creates one standalone HTML file.

That HTML file contains:

The portal design

The broadcast title

The message you typed

The purple cyberpunk style

The Safety is an illusion signature

No internet is required for someone to view the message once they are connected to the Biscuit portal.

Suggested Uses

Offline announcements

Emergency notes

Puzzle clues

Local community messages

Field guide information

Demo messages

Captive portal awareness projects

Important Notes

This is a one way broadcast.

People can read the message, but they cannot reply from this page.

This is not a chat system.

This does not collect messages.

This does not need a server.

The generated HTML file is meant to be uploaded directly to the Biscuit captive portal.
